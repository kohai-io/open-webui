# Custom feature ledger

This ledger records the initial disposition of custom functionality in the v0.6.36 fork at `7f562ebb5c0893a886adc02521251fce7b725cb2`. Decisions are deliberately biased toward a clean upstream baseline. Upstream equivalence must be verified against the exact v0.10.2 tag before porting or deleting code.

Disposition values are: `drop`, `use upstream`, `contribute upstream`, `extract to Studio`, and `retain as a small OWUI patch`.
